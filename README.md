# บันทึกรายรับ-รายจ่าย

เว็บแอปสำหรับบันทึกรายรับ-รายจ่ายส่วนตัว แนบรูปใบเสร็จได้ และดาวน์โหลดรายงานเป็น PDF รายเดือน/รายปี
ข้อมูลเก็บบน Firebase Firestore ทำให้เปิดดูและบันทึกได้จากทุกอุปกรณ์ผ่านลิงก์เดียวกัน โดยไม่ต้อง login

> **ข้อควรทราบเรื่องความปลอดภัย**: แอปนี้ตั้งใจไม่มีหน้า login เพื่อความสะดวก (ตามที่เลือกไว้)
> ใครก็ตามที่มีลิงก์เว็บนี้จะสามารถดู เพิ่ม แก้ไข หรือลบข้อมูลได้ทั้งหมด จึง **ไม่ควรแชร์ลิงก์นี้ให้คนอื่น**
> ถ้าต้องการความปลอดภัยเพิ่มเติมในอนาคต (เช่น ใส่รหัสผ่าน หรือ Google Sign-In) สามารถแจ้งให้เพิ่มได้ภายหลัง

## โครงสร้างเทคโนโลยี

- **Frontend**: React + Vite + Tailwind CSS
- **ฐานข้อมูล**: Firebase Firestore (Spark/free plan — รูปใบเสร็จถูกย่อขนาดแล้วเก็บเป็น base64 ในเอกสารเดียวกัน แทนการใช้ Firebase Storage เพื่อไม่ต้องผูกบัตรเครดิต/อัปเกรดแผน Blaze)
- **สร้าง PDF**: jsPDF + jspdf-autotable (ฝังฟอนต์ไทย Sarabun ไว้ในตัวแอปแล้ว)
- **Deploy**: GitHub Actions -> GitHub Pages

## สถานะการตั้งค่า

โปรเจกต์ Firebase ชื่อ **budget-tracker-wasin** ถูกสร้างและตั้งค่าให้แล้วโดยอัตโนมัติ (Firestore + Anonymous
Auth + security rules + GitHub Secrets) เว็บที่ deploy แล้วพร้อมใช้งานได้ทันทีที่ลิงก์ GitHub Pages ของ repo นี้

หากต้องการรันบนเครื่องตัวเองเพื่อพัฒนาต่อ:

```bash
npm install
cp .env.example .env
```

แล้วขอค่า Firebase config จากไฟล์ `.env` ที่มีอยู่แล้ว (หรือดูได้จาก Firebase Console > Project settings) มาใส่ในไฟล์ `.env` ที่สร้างใหม่ จากนั้น:

```bash
npm run dev
```

## การใช้งานแอป

แอปแบ่งเป็น 4 หน้า (แท็บใต้หัวเว็บ): **หน้าแรก**, **งานภาษี**, **กระแสเงินสด**, **ใบเสนอราคา** — เลือกเดือน/ปีที่กล่องด้านบนมีผลกับ 3 หน้าแรก (ใบเสนอราคาไม่ผูกกับเดือน/ปี เพราะเป็นเอกสารแยกตามลูกค้า)

### หน้าแรก
- กดปุ่ม **+** มุมล่างขวา เพื่อเพิ่มรายการ เลือกรายรับ/รายจ่าย ใส่จำนวนเงิน หมวดหมู่ วันที่ รายละเอียด และแนบไฟล์ใบเสร็จได้ (ไม่บังคับ) — แนบได้ทั้งรูปภาพและไฟล์ PDF (เช่น ใบกำกับภาษีที่เป็นไฟล์ดิจิทัลอยู่แล้ว) ไฟล์ PDF จำกัดขนาดไม่เกิน 650KB เพราะเก็บอยู่ใน Firestore โดยตรง (ไม่ได้บีบอัดให้เหมือนรูปภาพ)
- แนบรูปแล้วกด **"อ่านบิลอัตโนมัติด้วย OCR (ฟรี)"** เพื่อให้ระบบอ่านตัวเลขยอดเงินและเดาหมวดหมู่ให้ (ทำงานในเบราว์เซอร์ล้วนๆ ไม่มีค่าใช้จ่าย แต่ความแม่นยำขึ้นกับความชัดของรูป — ตรวจสอบก่อนบันทึกเสมอ) — OCR ใช้ได้เฉพาะไฟล์รูปภาพ ไฟล์ PDF ต้องกรอกเอง
- กดที่รูปย่อ/ไอคอน PDF ในรายการเพื่อดูไฟล์แบบเต็มจอ
- กด **ดาวน์โหลด PDF (รายเดือน)** หรือ **ดาวน์โหลด PDF (รายปี)** เพื่อสร้างรายงานรายรับ-รายจ่ายตามช่วงที่เลือกไว้
- กด **แก้ไข**/**ลบ** ที่แต่ละรายการเพื่อจัดการข้อมูล
- ติ๊ก **"มีใบกำกับภาษี (VAT)"** ตอนเพิ่ม/แก้ไขรายการ เพื่อบันทึกเลขที่ใบกำกับภาษี เลขผู้เสียภาษีของคู่ค้า และแยกยอดก่อน/หลัง VAT 7% ให้อัตโนมัติ — บิลที่ไม่มี VAT (ร้านไม่จด VAT หรือกิจการที่ได้รับยกเว้น) ไม่ต้องติ๊ก ปล่อยเป็นรายจ่ายปกติ

### งานภาษี
- สรุปยอดภาษีขาย, ภาษีซื้อที่เครดิตได้, และภาษีที่ต้องชำระ/ขอคืนของเดือนที่เลือก
- รายการภาษีขาย/ภาษีซื้อแยกเป็น 2 รายการ พร้อมเลขที่ใบกำกับภาษีและชื่อคู่ค้า
- กด **"ดาวน์โหลดรายงานภาษีซื้อ-ขาย"** เพื่อสร้าง PDF ไฟล์เดียว 2 แผ่น ("รายงานภาษีซื้อ-ขาย ประจำเดือน...pdf") แผ่นแรกเป็นรายการภาษีขาย แผ่นสองเป็นรายการภาษีซื้อ รูปแบบตารางกริดพร้อมหัวรายงาน (เดือน/ปีภาษี, ผู้ประกอบการ, ที่อยู่, เลขผู้เสียภาษี) เหมือนแบบฟอร์มที่ใช้ส่งนักบัญชี — ใบกำกับภาษีอย่างย่อจะไม่ถูกนับรวมในรายการภาษีซื้อ (เครดิตไม่ได้ตามกฎหมาย)
- แก้ไขข้อมูลกิจการได้จากหน้านี้ หรือกดไอคอน ⚙ ที่หัวเว็บได้เหมือนเดิม

### กระแสเงินสด
- สมุดเงินสดแบบไล่ยอด: ยอดยกมา (คำนวณจากทุกรายการก่อนวันที่ 1 ของเดือนที่เลือก) ตามด้วยตารางรายการวันที่/รายการ/รับ/จ่าย/คงเหลือ เรียงตามวันที่จริง ปิดท้ายด้วยยอดคงเหลือสิ้นเดือน

### ใบเสนอราคา
- กด **"+ สร้างใบเสนอราคาใหม่"** กรอกเรียน/Attn, ชื่อ/ที่อยู่/โทรศัพท์ลูกค้า, เลขที่ (ระบบเสนอเลขถัดไปให้อัตโนมัติแบบ QU + ปี พ.ศ. 2 หลัก + เลขรัน 5 หลัก แก้ไขเองได้), รายการสินค้า/บริการ (เพิ่ม/ลบได้หลายรายการ แต่ละรายการมีรายละเอียด จำนวน หน่วย ราคา/หน่วย คำนวณราคารวมให้อัตโนมัติ), ส่วนลด, และหมายเหตุ (ค่าเริ่มต้น "30 วัน" จะไปแสดงในช่อง "กำหนดยื่นราคา")
- ระบบคำนวณ รวมเงิน/ส่วนลด/ราคาสุทธิ/VAT 7%/รวมสุทธิ ให้อัตโนมัติ พร้อมแปลงยอดรวมสุทธิเป็นคำอ่านภาษาไทย
- กด **"ดาวน์โหลด PDF"** ที่แต่ละรายการเพื่อสร้างใบเสนอราคาตามฟอร์มมาตรฐานของกิจการ (หัวเอกสาร 2 ภาษาไทย/อังกฤษ พร้อมโลโก้ ดึงจากข้อมูลกิจการที่ตั้งค่าไว้)
- ใบเสนอราคาทุกใบถูกบันทึกไว้ แก้ไข/ลบย้อนหลังได้

กดไอคอน ⚙ มุมขวาบนเพื่อตั้งค่าข้อมูลกิจการ (ชื่อ หจก./บริษัท ไทย+อังกฤษ, เลขประจำตัวผู้เสียภาษี 13 หลัก, สำนักงานใหญ่/สาขา, ที่อยู่ไทย+อังกฤษ, โทรศัพท์, อีเมล) ข้อมูลนี้จะขึ้นหัวรายงาน PDF ทุกฉบับ (รวมถึงใบเสนอราคา) ให้พร้อมส่งนักบัญชี/ลูกค้า ระบบตรวจสอบ checksum ของเลขผู้เสียภาษีให้อัตโนมัติ (เตือนถ้ารูปแบบไม่ถูกต้อง)

## หมายเหตุ

- แอปนี้ไม่มีระบบ login และไม่ได้เปิดใช้ Firebase Authentication เลย (Anonymous Auth บนโปรเจกต์ Firebase ใหม่ต้องผูกบัตรเครดิต/แผน Blaze จึงข้ามไป) Firestore rules จึงเป็นแบบเปิด (`allow read, write: if true;`) — ใครก็ตามที่มีลิงก์เว็บนี้เข้าถึงข้อมูลได้ทั้งหมด ทุกคนที่เข้าเว็บนี้ใช้ข้อมูลชุดเดียวกัน
- รูปใบเสร็จจะถูกย่อขนาด/บีบอัดในเบราว์เซอร์ก่อนบันทึก (ไม่เกินประมาณ 900KB ต่อรูป) เพราะเก็บอยู่ในเอกสาร Firestore โดยตรง (จำกัดที่ 1MB ต่อรายการ)
- Firebase ใช้แผนฟรี (Spark plan) เพียงพอสำหรับการใช้งานส่วนตัว ไม่ต้องผูกบัตรเครดิต
- Security rules อยู่ที่ [`firebase-rules/firestore.rules`](./firebase-rules/firestore.rules) — แก้ไขแล้ว deploy ใหม่ด้วย `firebase deploy --only firestore:rules --project budget-tracker-wasin`
